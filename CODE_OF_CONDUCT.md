# Code of Conduct

Open FMEA aims to be a professional and respectful open source project.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent, but accept corrections when impact differs from intent.
- Focus technical discussion on evidence, reproducible behavior, and project goals.
- Give useful feedback without personal attacks.
- Respect different experience levels and communication styles.

## Unacceptable Behavior

- Harassment, intimidation, threats, or personal attacks.
- Discriminatory language or behavior.
- Public disclosure of private or sensitive information.
- Repeated disruption of technical discussion.
- Spam, trolling, or bad-faith participation.

## Scope

This code of conduct applies to project spaces, including issues, pull requests, discussions, releases, and other public collaboration channels related to Open FMEA.

## Enforcement

Project maintainers may remove comments, close discussions, restrict participation, or block users when behavior harms the project or its contributors.

If you see a problem, report it to the maintainers through GitHub. For security-sensitive issues, follow `SECURITY.md` instead of posting publicly.
